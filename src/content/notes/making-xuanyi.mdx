## 从一个 X 开始

这个网站的起点，是「把好奇心，做成看得见的作品」。视觉设计里最先被确定下来的，是两条相遇的曲线：一条代表探索，一条代表创造。它们交错之后，成为 XUANYI 的 X Mark。

X 不必像一个坚硬的字母。这里用圆润的端点、舒展的路径和轻微的明暗，让它像一个正在成形的想法。它可以被缩小放进导航，也可以独自在首页占据一块空间。

> 先让静止的形状成立，再让运动给它一点生命。

## 给留白一个理由

这个网站选择奶油白、清浅的天空蓝和深墨色。杏橙与薄荷绿只在需要一点变化的时候出现。

留白并不是页面之间的空隙。它决定一段话被怎样阅读，一件作品被怎样看见。首页的大字负责建立第一印象，作品的封面负责让项目变得直观，阅读页则把注意力交还给文字。

设计 Token 集中在 `src/app/tokens.css`。在源码中，颜色、间距与字体是可维护的选择，而不是散落在各处的临时数值。

```css
:root {
  --cream: #fafaf6;
  --sky: #dceffc;
  --ink: #233746;
  --apricot: #ffb98b;
  --mint: #b9dcc7;
}
```

## 让动效知道什么时候停下来

首页的顺序是：辅助文字先出现，大字展开，X Mark 随后进入，最后再落到介绍与作品入口。内容从一开始就可以访问，没有必须等完的片头。

鼠标带来的位移被控制在很小的范围。项目卡片的反馈同时改变裁切、图片位置与入口标签，让一个链接更像一个可以被打开的对象。

### 也照顾喜欢安静的人

系统开启「减少动态效果」时，入场动画与持续运动会关闭。移动设备使用重新组织的构图，也保留明确的按钮与原生滚动。

动画不是内容成立的前提。即使没有那些运动，这个页面也应该有清晰的层级、可读的文字与顺手的导航。

## 真实，比填满更重要

作品来自已确认公开的 GitHub 仓库。每个项目的状态、来源与体验入口都需要与仓库保持一致。图形化封面是为网站创作的概念表达，并非项目的真实界面截图。

这里没有用虚构文章填满列表。这篇制作记录是第一篇手记，也给之后的内容留出位置。

文章使用本地 MDX，作品使用 TypeScript 数据。无需数据库，也可以继续编辑、发布和维护。网站还远远不是一个终点；它只是给下一次好奇，留了一扇门。
