# Director comparison / 决策

正式首页不替换：两套是真实可操作的导演实验，尚不能证明整体优于现有2.2。A作为下一步研究方向保留，B作为空间构图对照，不将两套随意混合。

## 看过什么

在实际Chromium录制的 A/B 桌面及390px完整预演（约11秒）、原生滚动及反向、reduced录屏上作全时段2fps时间码序列审查；关键状态另有原始PNG。当前没有直接播放界面，不声称完成实时速度观看、真机或亚帧无抖动验收。原始WebM可直接下载播放复审。三浏览器四视口另有自动化；自动化不用于给美术打分。

## 画面判断

- 最好的镜头：A约4.5—5.5秒，X落向曲线的下沿，Intro在下方建立，方向可以被理解。比2.2缩到导航后直接换章节，多了一次可见接棒。
- 最弱的镜头：B约5—6秒，X已接近右侧边缘，而作品尚未充分建立，形成叙事空档。外层空间展开更明显，但因果关系比A弱。
- 最像模板的动作：两套作品入场依旧使用透明度与外层位移；B多一个透视展开，不能仅凭此宣称拥有原创的“作品世界”。既有Coverflow控制器可靠，但艺术语言仍需进一步融合。
- 应删的动作：A在稳定作品画面上继续保留完整环线，会穿过说明和技术标签，显得像示意图。已让引导线在项目接管焦点时退去。B已改为自己的短弧，不再借用A的大环线。
- 材质：保留Sculpted Silk是正确的；本轮不是一次新材质胜出。更猛烈的形变不会解决空间接续问题。
- 手机：单列标题、曲面、文案；中段Intro放低，与X分离，最后只突出中央项目。实验画布较高，需自然纵向浏览；尚不足以直接替代正式首屏的轻盈密度。
