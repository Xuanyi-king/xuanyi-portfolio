# The Passing Curve · Director’s Cut

运动：0–12%轻微错时舒展，12–27%有效停顿；30–56% X收束与曲线延伸为主动作；35–64%封面以裁切开口和外层水平落点展开；60–74%文字建立与曲线消退；76–100%完全静止。曲线采用固定几何、局部描边，不每帧重建d。不同阶段用不同缓动，文字不与X同时开始。

两种驱动共享纯状态映射。预演用10秒可暂停时钟。滚动用实际section位置与视口，无固定时长；桌面短sticky研究（只一段可用视口距离），手机普通文档流，无pin、多屏Hero或锁定。手机优先保留标题、CTA、中文和真实项目入口，短弧在上侧，不绕屏。
