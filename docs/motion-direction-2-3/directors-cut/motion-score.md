# Motion Score · The Passing Curve

这些是共享视觉映射的范围，实际观看以真实画面为准；不是要求用户按百分比或固定时长滚动。

|阶段|主动作|陪衬 / 阅读|
|---|---|---|
|Anticipation · 0–12%|原有云绸X轻微舒展，最大force9，回到品牌标准轮廓|标题与CTA保持稳定；没有项目/大轨道同时抢动|
|Hold · 12–26%|X、标题保持不动，约1.4秒预演停顿|给眼睛时间看交叉与曲面；真实滚动随时可离开|
|Main · 28–60%|X前段收束较快，曲线向接收边缘延伸，封面开口逐渐展开|主标题26–36%退出；Intro37%后出现；封面33%后展开，手机略早|
|Follow-through · 53–72%|封面收拢到中心；X在56–72%退出，开放曲线61–76%消退|元数据53–66%建立；平板Intro53%前撤离，避免阅读平面冲突|
|Settle · 64–76%|侧卡及展廊标记最后建立；手机预演的整个展廊短距离调整落点|66%即可操作作品，活动卡始终全强度；曲线在封面之外|
|Rest · 76–100%|所有过渡视觉保持最终状态|三个真实项目可拖动、切换、点击，没有自动轮播或常驻呼吸|

X横向收束、封面开口使用前段较快的三次减速；X尺寸变化用smoothstep并较晚结束；文字和侧卡独立错时smoothstep。没有把全部动作套进同一缓动。真正的高潮是X与封面同场的接棒，后半段停止服务于阅读。

0/25/40/50/60/75/90/100的实际图见[证据索引](../../evidence/passing-curve/README.md)。25%与0%相同的标准轮廓是有意的欣赏停顿，并非漏渲染。

桌面真实滚动只用section位置与0.8视口的推进距离。手机采用普通文档流：约530px Hero后接项目，整段1100px含作品内容；没有手机pin。手机原生滚动中删去曲线，因为X和作品没有在同一固定空间停留；Intro改放在两者之间。这是明确的简化与艺术局限，不宣称手机完整保留桌面空间效果。两种驱动调用同一passingFrame，布局与可见内容按视口独立编排，真实用户不必等待10秒。
