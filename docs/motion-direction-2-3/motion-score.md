# A Shape Becomes a World — Motion Score

实验路径 `/lab/motion-direction/`，10 秒实时网页预演。推荐继续研究 A Continuous Thread；未通过正式替换门槛，首页保持 2.2。两套共用真实 LivingX 与 LivingGallery，差异在构图、运动方向和接续线索，不只是缓动或颜色。

## ACT I / 0—2.3s · FORM

品牌、标题、CTA 从首帧可用。唯一主动作是两条曲带轻微受力并恢复，峰值 18 SVG 输入单位，小于正式交互上限。标题与字距保持静止；不以隐藏文字制造开场。短暂的形变把视线引向交叉处，随后停住，准备空间转移。A 的曲线从左侧标题旁向 X 靠近，B 的短弧只留作曲面环境线索。

## ACT II / 2.3—6.0s · TRANSFORMATION

A：大 X 向左下方让位，弧线展开到作品的水平落点；Intro 在3—4.2秒建立，4.8—6秒退去。标题在2.5—5秒退后，CTA 同时退出焦点顺序。主角由曲面转到连续路径，不能让 Intro 残影留在项目文字背后。

B：X 向右上侧退并转向，作品父平面从下向前展开；短弧随 X 退去，不另画一条长轨道。空间感更强，但 Intro 与作品出现之间的关系比 A 抽象。它保留为真实对照，不强行混合到 A。

## ACT III / 5.3—10s · EXPLORATION

作品在5.3秒开始进入，约7.9秒完全稳定，X 于5.6—7.2秒退出。作品可见后才获得交互，中心卡片、真实封面和标题成为主角。8—10秒保留为安静的操作窗口，轮播**不自动切换**；用户可用左右按钮、键盘、拖动和原生详情链接。录屏另保留一次真实操作，不假装固定10秒编排必定包含用户拖动。

## 控制权、可逆与降级

- directorFrame 是确定性的纯映射；时间预演、进度拖动、原生滚动互斥地提供同一个 progress。
- 曲面 d 仍只由 LivingX renderer / curve-owner 写入。实验 direct drive 是确定性姿态输入，暂停不再等待弹簧继续收敛；正式默认分支继续使用原弹簧，没有重写 Controller。
- 导演只控制 `.direction-mark` / `.direction-portal` 等实验外层 transform、opacity 和单条曲线的 dashoffset，不写 Gallery 卡片 transform，不重建路径。
- 时间模式每帧只更新 DOM refs，无整树 React 重绘；离页、偏好变化、隐藏页停止 clock，所有监听清理。
- 滚动模式为实验画布提供短 sticky 阅读窗口，不锁滚轮，不阻止纵向滚动。它不是正式首页的 pin 集成；快速上下均由绝对进度恢复。
- reduced-motion 不自动播放；滚动以三段静态构图切换，手动进度仍可观察静态姿态。无 JS 可通过常驻 Work 入口访问全部作品。

## 预算与主动舍弃

没有新依赖、滤镜、动态模糊、WebGL、常驻动画或自定义光标。曲面形变仅前2.3秒有输入变化；之后不反复提交相同值。原型的场景转场限于少量外层合成属性，保留原有性能长尾风险，不承诺稳定60FPS。未把候选叠加进正式首页，避免在连续性尚不成熟时增加生产成本。
