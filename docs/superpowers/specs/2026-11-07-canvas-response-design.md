# Living Canvas — response and measured polish

基线是执行时重新核验的 PR #3 head `811a2d4`；继续同一分支与 PR，不重写、不合并，不新增动画依赖。沿用既有 Editorial Flow、真实项目、静态内容与无障碍降级。

选择：在项目编号旁放一个小型 X，让展廊的连续虚拟速度成为有界受力输入。它不是导航，也不是新控制器。只通过现有 LivingX / curve-owner / living-spring 写几何；React 不逐帧传 state。比较过直接驱动 Hero X（作品区离屏，反馈不可见）与重启 X Rail（控件含义更复杂），不采用。减少动态效果、离开、resize、隐藏与卸载均归零/清理；纵向触摸、点击和原生链接保持既有行为。

曲面候选为 Sculpted Silk 的局部扭转与随形薄边，和当前版本在同视口、同姿态真实 A/B。只采用实际更好的部分；不增加大面积模糊或 WebGL。研究页可以展示候选，正式网站只采用一套。导航小标保持清晰，避免把材质细节搬进极小图标。

先保留生产基线与实际 Chrome trace / CPU profile，再改性能代码。追踪初始化、指针、滚动、按钮、拖动与导航；正常测量不启用 trace，避免把 profiler 开销计作产品改进。前后用相同脚本、主机、视口、CPU 配置复测，保留长尾与样本离散性，不宣称正式 INP 或真机 60FPS。

Folding Canvas 检查 25/50/75/90% 以及连续反向输入，桌面1440×900、手机390×844、窄屏320×740；中间帧与终点同等重要。只修复实际复现的不连续。当前没有 ADB、USB 或公开的 Android 远程调试能力，真机验收仍列未验证。

交付关键前后 JPEG、实际短 WebM、trace 和性能 JSON；大体积文件进入 CI Artifact，旧证据保留。一次独立终审，问题以回归验证；最终是否 Ready 取决于真实证据与明确边界。
