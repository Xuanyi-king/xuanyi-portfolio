## 方案与取舍（由设计负责人作出的实施选择）

- SVG 闭合曲面 + CSS3D（采用）：沿已有 cubic 中心线生成变宽轮廓、薄边、局部遮挡。可复用已验证实验分支的几何/收束代码，重做 Sculpted Silk 与 Translucent Fold 的实际同状态比较。一个几何 renderer 控制入场和弹簧；滚动只动外层。
- WebGL 曲面（不采用）：当前 2.5D 轮廓足以进入真实 A/B；在没有可见收益证据前，不引入渲染器与新的资源成本。
- 单纯放大描边 / 只 scale 卡片（不采用）：不足以体现曲面与空间关系。

用户要求直接执行，设计选择由团队自主比较，不加入额外审批流程。以浏览器渲染而非文档决定最终材质；已有实验仅复用，不重复验收后声称新成果。

## 展廊接口与行为

一个项目一个 article/详情链接，复用 ProjectScene 与真实素材；无镜像语义实例。独立 position 连续坐标，正模索引与有符号距离驱动 translate3d / rotateY / depth / scale。绕回发生在不透明度为零的深处。1 项静态；2 项采用单中心与淡出的紧凑布局；3/4/6 项逐渐扩大可见窗口但不强行展示五张手机卡片。

控制器只有一个可取消 RAF。press 立即中断惯性；方向锁定后水平拖动；普通 wheel 和纵向触摸保持页面行为。release 由有界速度预测目标并吸附；方向键/按钮累加目标；Escape 取消当前手势。Click、Drag、LongPress 分开。React 仅更新离散活动项目/可访问状态，不逐帧渲染。

中心链接直接进入详情，侧卡先居中；修饰键链接保留原生行为。roving focus，左右按钮，真实 01/03，polite 状态。真实影片仅中心明确 hover/focus 才请求与播放，离开、切换、隐藏、reduced 均停止。名称转场唯一，Work 网格保持原样。无 JS 用同一组语义内容还原普通静态网格。

先在 /lab/canvas-study 研究页比较两种材质与真实三项目展廊，合格后接入首页。可选 X Rail 只作清晰度比较；如果增加符号歧义，保留普通按钮/编号。研究页明确标注实验，不虚构额外项目；4/6 项为控制器测试数据，不作为公开作品。

## 验证

测试实函数/控制器的 1/2/3/4/6、正反100次、边界、惯性中断、取消与dispose。浏览器 CF/FF/WK ×1440x900/768x1024/390x844/320x740 验证曲面、滚动、拖拽、纵向触摸、点击/返回、键盘/reduced、resize/noJS。保留关键 JPEG，真实视频和大图进 Artifact。性能保留可复现脚本、RAF、长任务、CLS/LCP与交互延迟样本；不把模拟视口称为真机，不用短样本宣称60FPS。
