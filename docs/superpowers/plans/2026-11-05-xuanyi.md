# XUANYI Implementation Plan

Goal: Build an original, light, bilingual personal site with real public projects and quiet editorial reading.
Architecture: Next.js static export; server-rendered page content; small client islands for GSAP, filters, navigation, and the X playground. Content lives in typed data and local MDX. No database or AI service.
Tech: Next.js 16, React 19, TypeScript, SVG, GSAP, MDX.
Spec: User's PROJECT XUANYI brief in this conversation. User explicitly requests autonomous execution without stopping at plans.

## Constraints
- Identity: XUANYI / 玄屹; original curved X, no crown imagery.
- Public repositories only; no invented results, career, or articles.
- Cream, sky, ink, restrained apricot and mint; accessible mobile layouts.
- All required routes; reduced motion; keyboard focus; no blocking intro.

## Review focus
- Direct deep links and unknown slugs: generated routes and real 404.
- Filters: project category changes visible projects; empty search state is clear.
- MDX: headings, syntax highlighting, reading time and TOC match content.
- Narrow screens: title and artwork recompose with no horizontal overflow.
- Reduced motion / no JS: content remains visible and links usable.
