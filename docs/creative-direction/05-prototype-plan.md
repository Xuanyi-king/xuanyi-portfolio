## 每案的运动分镜合同

不能只写“GSAP 高级缓动”。每个动作先填：触发、被改变的关系、起/终态、运动峰值、可读停顿、中断/返回、降级、性能成本。

| 案 | 焦点与节奏提案 | 需要可见的证据 |
|---|---|---|
| A | 0–20% 保留轮廓；20–55% 光线/遮挡改变；55–70% 关键读句；70–100% 接至首件作品。百分比是实验分镜点，不是固定章节高度 | 文字与雕塑有前后关系，停顿时 CTA/关键文字可读；素材光线不随平面倾斜失真 |
| B | 0–25% 认出交叉；25–60% 展开与转面；60–80% 真实作品正面成立；80–100% 进入可横向探索状态 | 同一边界可追踪；逆滚不是突然换图；快滚不隐藏作品；不劫持整页滚动 |
| C | 100–150ms 反馈，约300–500ms 建立连接，之后静止可读。短时长是提案，由内容测试修订 | 点击/触摸/键盘等价；一次只强调一个关系；不因观赏动画延迟项目跳转 |

## 公平比较与验收

**内容一致：** 三案均使用 Router 真实设置局部、ATLAS 真实帧/可选片段、知乎真实界面，同样的介绍与手记；相同网络/CPU条件，不让一个版本靠更漂亮的虚构资产取胜。

**艺术观察：** 去掉名字后能否记住一个专属形式；五秒首印象能否知道“这是个人作品/实践”；文字与 X 是否互相组织；是否有一个可描述的运动高潮；进入真实作品是否更直接。记录原话和观察，不把主观审美伪装成自动测试分数。若邀请用户/参与者测试，由用户自行安排，不擅自联系第三人。

**代表尺寸与路径：** 1440×1000、1024×768、768×1024、390×844、320×740；至少 Chromium + WebKit 的实验检查。真实手机和 Safari 可用时单独确认，没有实测就明确标注。检查普通/快速/反向滚动、拖动中断、resize、可见性切换、方向键/Enter、原生详情/返回、200%缩放、reduced-motion、无 JS 的内容路径。原型不追求完整生产测试套件，但这些核心问题必须真实操作，不能只看截图。

**工程预算（下一轮目标，未达成声明）：**

- 不新增动画框架；先复用现有 GSAP、SVG、CSS3D 与数值控制器。实时三维 renderer 若确有必要，先记录具体包/体积/用途，再做局部实验，不默认安装。
- 现有约227KiB gzip JS 是比较基线。实验 A/B/C 分别控制额外首屏 JS 在约30/60/40KiB gzip 内；未激活的变体不进初始执行路径，随后按真实分析结果修订预算。
- 不把三套媒体同时加载。手机默认显示尺寸合适的 poster，视频在交互后加载；没有新增资产时总传输先不超过本轮约810KiB基线。材质资产需要增加时明确记录增量，首屏新增静帧初步预算150KiB以内。
- 不出现每帧 React setState 驱动雕塑；用 refs/controller，开销大的 path/stop 更新需先测量。静止后无无意义 RAF；卸载后不保留监听和 WebGL context。
- 以同环境相对比较：CLS目标≤0.1；4×CPU下记录帧间隔P50/P95、>50ms长任务和样本数量，不把桌面 headless 当真机60FPS保证。对比稳定基线退化超过约20%的版本先定位再选。
- 不使用 Taste 的公司站固定章节/禁轮播/统一 hover 作为原型硬验收；保留阅读、真实资源和可复查性能检查。
