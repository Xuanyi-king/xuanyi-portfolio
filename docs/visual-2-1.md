# XUANYI 2.1 — 好奇的形状

## 基线与真正要改的事

PR #1 在开始时未合并，最新 head 为 `471805f`。2.1 从该提交建立 `feat/xuanyi-2-1-art-direction`，以 2.0 分支作为 stacked PR 的 base，保留全部工程与历史。

实际查看了 PR #1 的五张指定截图，并用 FFmpeg 对三段真实 WebM 按时间采样，检查运动先后与结束状态。没有用 README 代替画面观察。基线的主要美术问题：

1. 超大 XUANYI、左下标语、右下 X 各自成块，字体与符号缺少一条共同的视线关系。
2. X 的圆端、宽亮边和较重模糊投影叠加，更像充气软胶；材质与编辑式字体没有呼应。
3. 重要中文介绍与辅助标签普遍偏小，手机 `takes shape.` 视觉词距紧；巨大名字与细小说明之间跳级明显。
4. 两幅概念封面和真实项目隔了一层，第一眼难以理解项目内部；详情页重复同一种“截图+说明”节奏。
5. 原 Hero 录屏的早期采样出现已经绘制的名字再次被隐藏，属于初始绘制与迟到 JS 动画的机制问题。

## 真实比较与取舍

[studies](evidence/visual-2-1/studies) 是实际 React 网站在同一视口下的渲染截图。备选通过真实页面的 DOM/CSS 原型比较，没有使用生图。最终产品不保留切换方案或隐藏的备选页面。

- **Editorial Flow（选用）**：主句成为字体核心，Curiosity 的衬线斜体与 takes 的无衬线形成节奏，一条细线把文字空间延展到 X；手机顺序是标题、X、中文、CTA。
- **Playful Canvas（未选用）**：超大名字、自由标语和蓝色画布；桌面仍重复 2.0 的大字块，手机底块挤到标语，显得更像通用封面。
- **Glass（未选用）**：半透明交叠，但中间发灰、圆端仍接近软胶。
- **Paper（未选用）**：纯色、平切端点，清楚但过平，缺少适当的曲面层次。
- **Silk（选用）**：保留原始双曲线，收窄带宽、平切端点、蓝杏两色、细边与较轻投影。导航和 Favicon 对同一轮廓作加粗、实色的小尺寸光学校正。

两次独立视觉审查实际查看比较图及最终页面图，均选择 Editorial Flow + Silk。最终又去掉静态中心刻线，避免材质看起来被机械切割；保留较淡的细边与曲面光感。

## 首屏时间轴与加载机制

| 时间 | 画面 |
| --- | --- |
| HTML 首帧 | 名字、主句、中文、CTA 和可识别的 X 已可见、可点击 |
| 0.05—1.50s | 第一条曲带沿自身控制点舒展、轻微越过再回到品牌轮廓 |
| 0.18—1.63s | 第二条曲带错时舒展，形成交汇 |
| 0.12—1.92s | 杏色导线顺着版面向 X 行进并自然淡出，留下安静的底线 |
| 收束后 | 指针弹簧接管曲线；滚动只轻移引导线，阅读区保持平静 |

这些初始运动由 CSS 随 HTML 开始，不依赖 GSAP chunk 的到达时刻。主文字没有 opacity=0、遮罩隐藏或延迟再入场。支持 CSS `d:path()` 的浏览器看到曲线舒展，不支持时保留完整静态 X 和线条节奏；减少动态效果关闭装饰运动。一个很小的 head 脚本只记录本标签页访问状态，在首次绘制前为重复访问选择安静状态；无法访问存储时保留普通静态内容与 CSS 运动。客户端有 StrictMode 重放防护。

没有把 200ms 改成更大的阈值。GSAP 只增强滚动，文字是否可读与脚本速度无关。首屏入场与 LivingX 的 DOM 路径控制在交接前不争抢同一条曲线。

## 作品、内容与真实个人表达

- Router：概念封面通过遮罩展开成原仓库真实设置页局部；详情围绕“选择、解释、保留余地”，完整界面与三条规则并置。
- Film：聚焦/悬停才请求真实影片 8 秒静音节选，约 106 KiB；没有首页一次请求大量视频。详情给出真实 03/26/49 秒帧、节选控件和完整来源。
- Multiverse：保留真实首页，详情用原仓库“经历揭示 / 推演第一幕”截图组成档案。明确公网已下线，未虚构终局或当前在线运行。
- 可见的完整 ProjectScene 参与原生转场，项目名在图片外。键盘预览与鼠标预览合并状态；触摸直接进入详情。
- About 从三个具体项目出发讨论可解释的系统、画面中的知识和保留证据的叙事。没有编造个人经历、学历、奖项或私密动机；未提供的信息在 `src/data/about.ts` 保留空字段。
- 正文、说明、按钮和目录提高到实际可读字号；手机主句用明确的 flex 词间距，平板介绍显式分行，避免孤字。

## 主动删掉的效果与技术选择

移除旧 Hero 巨型名字的主导构图、圆润软胶式厚边、较重阴影、星形与轨道标签、重复的全段淡入/文字再隐藏时间轴、旧 Hero 的数百行断点覆盖。Lab 颜色用明确色板代替整体 hue-rotate，避免把焦点和两条曲带一起染色。

没有新增依赖。现有 GSAP、SVG、CSS 足够表达；不引入 Motion、Three.js、Theatre.js、mo.js 或新的滚动引擎。拒绝全局光标、阻塞片头与大场景。字体继续使用本地 Manrope（OFL）与系统衬线/中文字体。
